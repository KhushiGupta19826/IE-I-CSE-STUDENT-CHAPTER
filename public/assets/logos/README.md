# Logo Assets

Place the following files here to replace the placeholders:

- `iei-logo.png` — The official IE(I) logo (used in Navbar and Footer)
- `chapter-logo.png` — Chapter-specific logo (if separate from IE(I) logo)

The IEILogo component in `/src/components/IEILogo.jsx` will automatically
use `iei-logo.png` once it is placed here. No code changes needed.
