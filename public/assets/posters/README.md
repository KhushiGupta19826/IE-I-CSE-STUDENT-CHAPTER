# Event Poster Assets

Place event poster images here. The filename must match the `poster` field in `/src/data/events.js`.

Current expected files:
- code-or-creeper.jpg
- web-forge.jpg
- ai-ml-conclave.jpg
- buildsprint-2026.jpg
- git-bootcamp.jpg
- dsa-sprint.jpg
- linux-workshop.jpg
- tech-talk-career.jpg

Recommended size: 800x1200px (portrait, 2:3 ratio)
Format: JPG or WebP for best performance

If a poster is missing, the SafeImage component will show a polished placeholder
with the event title and category.
